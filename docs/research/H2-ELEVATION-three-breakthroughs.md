Breakthrough 1: Turn NOT COVERED into Executable Falsification Test Harnesses
 * The Problem: When a change cannot be translated 1-to-1 (e.g., converting milliseconds to seconds or splitting code.namespace + code.function), static generation stops.
 * The World-Class Fix: For every NOT COVERED mutation, invar compat emits a Zero-Dependency Falsification Test Harness.
 * Mechanics: Instead of telling the developer/agent "we didn't translate this," INVAR outputs a deterministic unit test fixture (e.g., in Go, TS, or Python) asserting expected input/output transformations and boundary conditions.
 * The Result: If an AI agent or engineer writes a hand-crafted bridge for a complex mutation, invar judge runs the generated test harness in CI. The PR cannot merge until the hand-written coping logic passes the exact test harness generated by INVAR.
Breakthrough 2: Position INVAR as the Un-Bypassable Compiler for AI Agents
 * The Problem: AI agents write unchecked coping code based on lossy prompt context.

 * The Result: INVAR becomes the mandatory execution boundary for AI coding agents. The agent handles the syntax; INVAR guarantees the mathematical contract.
