INVAR v0.1.0-alpha.25 (prerelease)

## New: SARIF export (become the format, not the feature)

`invar check --sarif out.sarif` writes a SARIF 2.1.0 report that
GitHub code scanning (and every SARIF consumer) ingests natively:
violations as errors located at the consumer read sites, stated blind
spots as notes under their stable reason codes (a blind spot rides
into the platform UI instead of disappearing), holds emit no result,
and the measured record travels in run properties so the export can
never read as an effectiveness claim. First move of the locked
declaration-graph strategy
(docs/architecture/strategy/DECLARATION-GRAPH.md). 46 of 46 tests
green. Held-out record unchanged: 38 of 70.
