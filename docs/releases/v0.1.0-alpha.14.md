INVAR v0.1.0-alpha.14 (prerelease)

## New: A4 field-level dependents graph (local-first)

`invar dependents <Type.field | field> --locks <dir> [--producer substr]
[--format json]` answers "who depends on this producer field" from local
invar.lock files. Zero network by construction (the module has no resolver
and no token). Deterministic sorted output. Unparseable lockfiles are
stated and exit 4; no parseable lockfile is exit 3; the command never exits
1 (it holds no verdict). A scoped query that misses but matches unscoped
spec-producer bindings says so instead of showing a bare zero.

The A4 gate (MOAT.md) is NOT met by shipping: it counts only when a
producer uses the answer to change or delay a removal in a real repository.

## Unchanged

Detection rules and verdicts identical to alpha.11 through alpha.13;
held-out record 38 of 70 caught, R1 FALSIFIED.
