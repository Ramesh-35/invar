INVAR v0.1.0-alpha.13 (prerelease)

## New

- A2.1: `invar receipt export --in-toto <receipt>` wraps a format 1 receipt
  as an in-toto Statement v1.0 (subjects = content-addressed inputs,
  predicate = the format 1 body verbatim). Additive view; format 1 stays
  canonical.
- Baseline ceremony: sign the lock with
  `ssh-keygen -Y sign -n invar-lock -f <key> invar.lock`; then
  `invar check --lock-signers <file> --lock-principal <name>` (and the same
  on `invar lock`) refuses to evaluate unless `invar.lock.sig` verifies.
  Fail closed to exit 3; without the flags behavior is unchanged.

## Unchanged

Detection rules and verdicts identical to alpha.11/alpha.12; rule expansion
stays frozen; held-out record 38 of 70 caught, R1 FALSIFIED.
