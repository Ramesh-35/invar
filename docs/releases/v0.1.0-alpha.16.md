INVAR v0.1.0-alpha.16 (prerelease)

## New: observed-reality locking (single sample)

`invar lock --sample <payload.json>` records the SHAPE of a real payload
(path and type pairs; values never copied), with PII-suspect warnings
(warn, never block) and 90-day staleness ([not-evaluated:stale-sample],
exit 4). `invar check --sample <fresh.json>` compares a fresh payload's
shape against the locked one. Lock format 2.

## Unchanged

Static rules identical to alpha.15; held-out record 38 of 70.

Release confirmed 2026-10-11: full asset set with checksums and SSH
signatures.
