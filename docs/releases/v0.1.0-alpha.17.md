INVAR v0.1.0-alpha.17 (prerelease)

## New: DX honesty batch

Every `invar check` now ends with the fixed two-line record: a summary
line (held | violated | skipped or not evaluated) and the measured
held-out record, whatever the counts. Stable, severity-free,
append-only reason codes on every not-evaluated statement
(docs/reference/REASON-CODES.md). Command help reordered product-first
with exit codes stated.

## Unchanged

Verdict semantics identical to alpha.16; held-out record 38 of 70.

Release confirmed 2026-10-11: full asset set with checksums and SSH
signatures.
