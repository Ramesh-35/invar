INVAR v0.1.0-alpha.7 (prerelease)

## New: signed release binaries

- Every binary archive is published with an SSH signature (`.sig`, namespace
  `invar-release`), verified by the release job before publishing.
- The GitHub Action verifies checksum and signature before it runs `invar`,
  against the key in `action/release-signers` at the ref you pinned. A failed
  signature stops the job, with no fallback. Unsigned releases (alpha.6 and
  earlier) are refused by this Action version.
- See docs/reference/RELEASE-SIGNING.md, including how to verify by hand.

## Unchanged

The engine is identical to v0.1.0-alpha.6 apart from the version number.
Detection on held-out data is unchanged: 13 of 25 real in-scope breaks caught
(48% missed); R1 remains FALSIFIED.

## Not claimed

This is key-based signing, not a build-provenance attestation or a public
transparency log; those are deferred while the repository is private.
