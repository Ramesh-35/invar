INVAR v0.1.0-alpha.18 (prerelease)

## New: multi-sample presence witnesses

Observed-reality locking upgraded from one sample to witness counters
(present/absent/null and observed types per path, across N observations;
lock format 3; formats 1, 2 and 3 all read forever). Drift is VIOLATED
only when a path was present in every observation with at least 3
observations; optional fields and low witness counts are stated
([not-evaluated:optional-field-absent], [not-evaluated:witness-count-low]).
Output honesty fix: stated non-evaluation prints even when the contract is
also VIOLATED.

## Unchanged

Static rules identical to alpha.17; held-out record 38 of 70.

Release confirmed 2026-10-11: full asset set with checksums and SSH
signatures.
