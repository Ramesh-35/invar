INVAR v0.1.0-alpha.21 (prerelease)

## New: reproduction guard and archival verification

Engine verdict semantics UNCHANGED from alpha.20; this release carries
data, tooling and one new acceptance test:

- Test 42 runs the standalone scorer against the committed corpus
  export and engine-of-record results inside `cargo test`, so every CI
  run re-proves that the public 38 of 70 record reproduces from the
  repository's own bytes. Drift in the export, the results file or the
  scorer's disclosed matching rule fails the suite.
- scripts/swh-verify.sh re-checks every origin in SWH-ARCHIVAL.tsv
  against the live Software Heritage archive (exit 0 all archived, 1
  any absent, 3 check failure); a weekly workflow for it ships as
  swh-archival.yml.new for founder installation.
- First release after going public; Zenodo integration is active, so
  this tag mints the corpus DOI.

Held-out record unchanged: 38 of 70, reproducible.
