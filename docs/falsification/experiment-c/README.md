# Experiment C: INIT-DISCOVERY ground truth and evaluation protocol

Status: ground-truth audit ACCEPTED as the working baseline (directive
58317, 2026-10-13). INIT-DISCOVERY is not implemented; no engine result
exists. Do not read anything here as an engine result.

Files:
- DEFINITION.md: the qualifying-contract definition, frozen before the
  audit opened any repository.
- corpus.tsv: the 30 repositories with recorded HEAD commits.
- labels.tsv: per-repository ground-truth labels.
- GROUND-TRUTH-REPORT.md: the audit report (evidence for every positive,
  explicit negative and ambiguous cases, limitations).
- EVALUATION-PROTOCOL.md: metrics, thresholds, reporting rules.

Workspace rule (H2, directive 64182, clarified by directive 73814): a
repository is a multi-package workspace only when its markers establish
at least 2 qualifying packages; the marker-to-evidence table is in
docs/architecture/INIT-DISCOVERY.md, "Workspace evidence". Corpus
repositories that fail this rule stay in the 30-repository frame with
their recorded labels; the rule never shrinks the evaluation frame.
Schema files are inventory-only in v1 (H1) and, like abstentions, are
never evaluated as proposals (EVALUATION-PROTOCOL.md, "Outcome
accounting").

Reproduce the audit's candidate lists (labels themselves are human
judgments and are not regenerated by script):
1. Clone each repository in corpus.tsv and check out its recorded HEAD,
   into scripts/experiment-c/repos/<owner>__<name>.
2. Copy docs/falsification/experiment-c/corpus.tsv into
   scripts/experiment-c/, then from there run `python3 locate.py`: it
   reads corpus.tsv and repos/ from its working directory and lists
   packages and every cross-package import (no field filtering), and
   writes locate.json, which step 3 reads.
3. `python3 review.py https://github.com/<owner>/<name> <limit>` prints,
   per shape-import candidate, declared fields and consumer mentions for
   human verification.
Step 1 is manual: the scripts do not read corpus.tsv's head column or
check out commits, so this is not an end-to-end automated reproduction.
Known locator history: the pnpm parser originally read any YAML list
item as a package glob, and the TypeScript shape pattern originally
missed `Readonly<{` aliases; both were found and fixed during the audit
and are recorded in GROUND-TRUTH-REPORT.md.
